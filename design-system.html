DESIGN SYSTEM

The pieces behind this site.

Two typefaces, one purple, and a handful of components, each in light and dark mode. Every color here is read live from the site’s CSS, so this page is always up to date.

Color

Every color is a token named for its job, with one value for light mode and one for dark. Text colors pass WCAG AA (4.5:1) against the page in both modes.

TokenLightDark

Type scale

Two typefaces: Crimson Text for headings, Inter for everything you read or click. Each style is shown as the site uses it. (The full type scale adds every weight of its typeface.) Phone sizes take over below 760px wide.

Button
Pill, 13 × 32 padding, accent background. Darker on hover in light mode, lighter in dark.
Text button
Accent text, the arrow nudges right on hover.
Chip
Pill outline, in two colors. Gray (secondary khaki) for tags like Finance; purple (accent hover outline, heading text) for “In use” in the type scale.
Outlined card
Two types: Stat (a number over a line of text, centered) and Chip (title, chips, then text). 1px border, radius m (16). Solid purple in light, a purple gradient in dark.
Input
Underline only, in six states: default, focused and focused while typing (purple), completed, error (red, with the message under it) and disabled (gray). Its label sits above it in body/s; the password form hides the label but screen readers still read it.
Back to top
44px circle, 1.5px rule outline (the icon’s stroke weight), gray Heroicons arrow-up. Sits right-aligned above the pager line, hidden until the visitor reaches the last section (e.g. Reflection), then pops in 1s later with a slight bounce. Purple on hover, focus and press; the arrow nudges up on hover and the button shrinks a little when pressed.
Nav bar
64px tall. On desktop: the logo, the links and the theme switch; Work opens a menu of the case studies. On phones the links move into a menu behind the ☰ button. The current page is underlined.
Footer
“Let’s connect” (heading/connect) with email and LinkedIn links, then the colophon (body/xs, italic). Centered, on every page.

Icons

One set: Heroicons, outline with a 1.5 stroke, solid for the active light/dark icon. The only exception is the LinkedIn logo.
